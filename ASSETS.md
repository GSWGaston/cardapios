# Créditos das imagens

As imagens são demonstrativas e estão armazenadas localmente. O app utiliza arquivos WebP otimizados em `public/images/`. As fontes originais utilizadas na conversão estão em `assets/originals/`.

## Fotografias dos produtos

Origem: [Unsplash](https://unsplash.com), sob a [licença Unsplash](https://unsplash.com/license). Os arquivos foram redimensionados e convertidos para WebP. As imagens são ilustrativas das combinações descritas.
